# Infrastructure as Code Based Cloud Deployment using Terraform and Ansible

## Project Overview

This project demonstrates Infrastructure as Code (IaC) by using
Terraform to provision two Ubuntu EC2 instances on AWS and Ansible
to configure both servers and deploy a static Nginx webpage.

## Technologies

- Amazon Web Services (AWS)
- Terraform
- Ansible
- Ubuntu
- Nginx
- Git and GitHub
